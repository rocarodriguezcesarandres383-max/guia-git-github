Guía paso a paso de Git y GitHub

Aprendiendo a crear proyectos, controlar versiones y subir repositorios.

1. Crear un proyecto en el escritorio

Primero debemos crear una carpeta en el escritorio de nuestra computadora.

  1. Hacer clic derecho en el escritorio.
  2. Seleccionar Nuevo y después Carpeta.
  3. Asignar un nombre al proyecto.
  4. Abrir Visual Studio Code.
  5. Seleccionar Archivo y después Abrir carpeta.
  6. Buscar y abrir la carpeta del proyecto.

2. Inicializar Git

Git permite controlar los cambios realizados en nuestro proyecto.

Abrimos la terminal de Visual Studio Code y ejecutamos:

git init

Configuramos nuestro nombre y correo electrónico:

git config --global user.name "Tu Nombre"
git config --global user.email "tu correo"

Para utilizar la rama principal llamada main:

git branch -M main

3. Crear tres commits con descripción

Los commits permiten guardar diferentes versiones de nuestro proyecto.

Primer commit: estructura del proyecto

git add .
git commit -m "Primer commit: crear estructura del proyecto"

Segundo commit: funcionalidad del DOM

git add .
git commit -m "Segundo commit: agregar funcionalidad DOM"

Tercer commit: mejorar los estilos

git add .
git commit -m "Tercer commit: mejorar estilos del proyecto"

Para comprobar los tres commits ejecutamos:

git log --oneline

4. Crear un repositorio público en GitHub

GitHub es una plataforma que permite almacenar y compartir proyectos.

  1. Ingresar a GitHub.
  2. Iniciar sesión con nuestra cuenta.
  3. Presionar el botón New repository.
  4. Escribir el nombre del repositorio.
  5. Seleccionar la opción Public.
  6. Presionar Create repository.

5. Conectar el proyecto con GitHub

Después de crear el repositorio, debemos conectar nuestra carpeta local con GitHub.

Copiamos la dirección HTTPS de nuestro repositorio y ejecutamos:

git remote add origin URL_DE_TU_REPOSITORIO

Comprobamos la conexión:

git remote -v

6. Manipulación del DOM

El DOM permite modificar el contenido de una página HTML mediante JavaScript.

Bienvenido a nuestra guía de Git y GitHub.

7. Subir el proyecto a GitHub (Push)

Para enviar nuestro proyecto al repositorio remoto ejecutamos:

git push -u origin main

Este comando permite subir los archivos y commits de nuestro proyecto a GitHub.

8. Comprobar el repositorio

Finalmente ingresamos a nuestro repositorio de GitHub y comprobamos que aparezcan los archivos del proyecto.

  • index.html
  • style.css
  • script.js

También podemos revisar el historial de commits para comprobar los cambios realizados.

9. Evidencias para entregar

Según las instrucciones de la actividad debemos presentar:

  • Capturas del trabajo realizado con Git.
  • Capturas de los tres commits con sus descripciones.
  • Captura del repositorio de GitHub con los archivos.
  • Enlace público del repositorio de GitHub.
